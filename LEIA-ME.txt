# Itaitinga MTB Race — versão sem Node

Esta pasta é um site estático. Não há Node.js, npm, Wrangler, banco de dados, API ou servidor de processamento.

Arquivos:
- index.html
- style.css
- app.js
- assets/moldura.png

## Publicação

Você pode publicar os arquivos usando uma hospedagem de arquivos estáticos que aceite upload pelo navegador.

No Cloudflare, use uma opção de hospedagem de Static Assets/Pages disponível no seu painel e envie o conteúdo desta pasta. Não é necessário instalar Node no computador.

## Funcionamento

A foto do participante é processada no próprio navegador:
1. escolhe a foto;
2. arrasta e aplica zoom;
3. a moldura é desenhada por cima;
4. o navegador gera o JPG;
5. o participante baixa ou compartilha.

A foto não é enviada para o servidor por este site.
